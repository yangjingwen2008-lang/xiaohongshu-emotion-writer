# 《潮湿雨季》完整使用说明

- 版本日期：2026-09-11
- 目录示例（可自选）：`D:\Projects\xiaohongshu-emotion-writer`
- 应用地址：`http://127.0.0.1:8765`

## 1. 这是什么

“潮湿雨季”是一套面向单个小红书账号的 Windows 本地情感随笔创作工作台。它把选题、写作、人工修改、风格训练、质量检查、封面、发布包、发布后复盘和评论回复辅助串成一条完整流程。

它的核心原则是：

- 内容、版本、截图和分析结果主要保存在你的电脑中。
- DeepSeek、Tavily 等联网能力只在相应步骤需要时调用。
- 每个重要动作都设有人工确认门，模型结果不会直接覆盖人工稿。
- 系统不会登录小红书，不读取 Cookie、验证码或私域后台。
- 系统不会自动发布、自动评论或自动回复。

## 2. 五分钟快速开始

第一次使用按下面顺序操作：

1. 确认电脑已安装 Python 3.11 或更高版本，以及 Node.js 22.12+ / npm。
2. 双击项目根目录的 `安装潮湿雨季.bat`，等待依赖安装、前端构建和数据库迁移完成。
3. 双击 `启动潮湿雨季.bat`。
4. 浏览器打开 `http://127.0.0.1:8765` 后，进入“设置”。
5. 填入 DeepSeek API Key；需要公开热点搜索和有限公开网页核验时，再填 Tavily API Key。
6. 分别点击“测试 DeepSeek”和“测试 Tavily”，确认连接正常。
7. 回到“工作台”，填写主题、情绪和可选补充要求，开始第一篇文章。

日常使用只需：

- 启动：双击 `启动潮湿雨季.bat`。
- 停止：双击 `停止潮湿雨季.bat`。
- 重新打开页面：在浏览器访问 `http://127.0.0.1:8765`。

## 3. 安装说明

### 3.1 运行条件

- Windows 10/11。
- Python 3.11 或更高版本，命令行中可以执行 `python --version`。
- Node.js 22.12+ 与 npm，命令行中可以执行 `node --version` 和 `npm --version`。
- 首次安装依赖时需要联网。
- 使用 DeepSeek、Tavily 时需要联网并拥有对应 API Key。
- 本地截图 OCR 依赖 Windows 中文 OCR 能力，不需要 OCR API Key。

### 3.2 推荐安装方式

打开项目目录：

```text
D:\Projects\xiaohongshu-emotion-writer
```

双击：

```text
安装潮湿雨季.bat
```

安装程序会依次完成：

1. 创建 `.venv` Python 虚拟环境。
2. 安装后端及测试依赖。
3. 安装前端 npm 依赖。
4. 构建前端生产文件。
5. 把 SQLite 数据库升级到最新结构。

看到“安装完成”后，再关闭窗口。

### 3.3 PowerShell 安装方式

在项目根目录打开 PowerShell，执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\bootstrap.ps1
```

### 3.4 “Multiple top-level packages discovered”怎么处理

这个错误表示旧安装配置把 `data`、`logs`、`frontend`、`uploads` 等目录误认为 Python 包，因此 `setuptools` 拒绝继续构建。当前项目已经在 `pyproject.toml` 中明确限定只打包 `backend` 相关模块。

如果仍看到这个错误：

1. 确认你运行的是当前项目根目录中的 `安装潮湿雨季.bat`，不要运行旧副本。
2. 打开 `pyproject.toml`，确认存在 `[tool.setuptools.packages.find]`。
3. 先关闭所有“潮湿雨季”窗口。
4. 将旧 `.venv` 文件夹重命名为 `.venv_old`，保留作回退，不要动 `data`、`uploads` 和 `exports`。
5. 重新运行 `安装潮湿雨季.bat`。

安装成功后可以再手动删除 `.venv_old`；它不包含文章数据库。

## 4. 启动、停止与局域网使用

### 4.1 本机模式

双击 `启动潮湿雨季.bat`。启动器会复用当前项目的健康服务，核对身份后清理无响应旧实例，并等待健康接口真正就绪；只有服务启动成功后才会打开浏览器：

```text
http://127.0.0.1:8765
```

这是最安全、最推荐的使用方式，只有本机可以访问。

### 4.2 局域网模式

需要在同一家庭网络中的手机访问时，先停止已有本机服务，再双击：

```text
启动潮湿雨季_局域网.bat
```

窗口会显示类似 `http://192.168.x.x:8765` 的地址。手机和电脑必须连接同一可信网络。应用不会自动修改 Windows 防火墙；如果系统弹出防火墙提示，只允许“专用网络”，不要开放到公共网络。

### 4.3 正确停止

双击 `停止潮湿雨季.bat`。不要只关闭浏览器，因为关闭网页不会停止后台服务。

## 5. 首次配置

打开左侧“设置”，完成以下内容。

### 5.1 DeepSeek

DeepSeek 用于：

- 三套创作方案、细节问题和初稿生成。
- 风格特征提取。
- 去 AI 味、风格、引用和风险等结构化审阅中的模型步骤。
- 热点整理。
- 单篇、周度和月度复盘。
- 用户逐条授权后的评论回复建议。

填入 API Key，模型名默认使用界面当前建议值。模型名称随供应商更新时，可以在设置页手动修改。保存后点击“测试 DeepSeek”。

### 5.2 Tavily

Tavily 用于：

- 从可公开搜索的网页中查找热点线索。
- 对当前稿件做有限公开网页相似度检查。
- 为正文仍保留的文化引用查找公开证据。

不使用公开搜索时可以不填 Tavily Key，但热点联网刷新和公网核验会不可用。保存后点击“测试 Tavily”。

### 5.3 Key 保存位置

Windows 本机模式下，API Key 默认进入 Windows 凭据管理器，不写入数据库、前端、日志或 Git。设置页输入框留空再保存，表示保留已有 Key。

Docker 无法直接使用宿主机凭据管理器。Docker 模式需要把 `.env.example` 复制为 `.env` 后填写；`.env` 不应发给别人，也不应提交到 Git。

## 7. 推荐的完整创作流程

### 7.1 第一步：输入主题和情绪

在“工作台”点击“写下一个还没说完的念头”，填写：

- 今日主题：尽量写成一个具体处境，而不是宽泛概念。
- 主要情绪：例如延迟性痛感、依恋、羞耻、释然。
- 补充要求：可写不想出现的意象、必须保留的语气、人物边界等。

示例：

```text
主题：分开以后，我开始绕开那条街
情绪：延迟性痛感
补充要求：不要写复合，不使用“救赎”这个词，结尾留白
```

点击“生成创作流程”。

### 7.2 第二步：从三套方案中选择一套

系统会生成三套有明显差异的结构化方案。重点比较：

- 开头进入方式是否自然。
- 情绪变化是否符合真实经验。
- 场景、意象和结构是否与历史文章过度重复。
- 结尾是留白、回望还是轻微转折。

选择一套方案后继续。没有选中的方案不会自动混入正文。

### 7.3 第三步：只确认一个关键细节

系统会提出一个细节问题，并给出三个安全虚构选项。你可以：

- 选择一个虚构细节；或
- 输入自己的真实细节。

真实细节只应填写你愿意写进文章的内容。确认后系统才生成初稿。

### 7.4 第四步：生成并人工修改初稿

初稿包含正文、备用标题、封面短句、标签、置顶评论和发布时间建议。正文目标为 600～900 字。

在富文本编辑器中修改标题和正文，然后保存。每次保存都会创建新版本，原始 AI 初稿不会被覆盖。

建议重点人工检查：

- 是否出现并不存在的经历。
- 人物关系和时间线是否准确。
- 是否过度解释情绪。
- 是否有“像模型总结”的段落。
- 结尾是否仍然像你的账号。

### 7.5 第五步：运行五项质量门禁

点击“运行五项质量门禁”，系统会检查：

1. 风格：与编辑宪法及已确认风格规则是否一致。
2. AI 味：套话、机械排比、抽象总结和解释过度等问题。
3. 原创度：本地历史、人工补充来源和 Tavily 可访问公开网页范围内的相似风险。
4. 文化引用：当前正文保留的电影、书籍、歌词、名言等出处。
5. 风险：平台风险、隐私、未经依据的诊断和其他阻止项。

重要说明：原创度检查不是“全网查重”。登录内容、验证码页面、客户端内内容、未被搜索引擎收录页面和私域内容均不在覆盖范围。

如果某个文化引用未核实或只能部分核实，提交按钮会被阻止。可以删除确定性出处，或改写为个人化感受，再重新运行质量门禁。

### 7.6 第六步：人工确认提交审核

只有当前检测范围通过且没有高风险阻止项时，“人工确认提交审核”按钮才可用。提交后正文进入待审核状态，但仍不会自动发布到小红书。

## 8. 热点候选怎么使用

### 8.1 手动刷新

在工作台“今日热点候选”点击“手动刷新”。需要已配置 DeepSeek；联网公开来源还需要 Tavily。

一次正常刷新最多进行有限次数的公开搜索和结构化整理。任一上游失败，本次立即停止，不会自动重试或悄悄换源。

候选会展示：

- 来源平台和证据链接。
- 抓取时间和趋势依据。
- 女性情感切口。
- 账号匹配度与同质化风险。
- 可信度和数据边界。

候选少于 3 个时，系统会显示“本次数据不足”，不会硬凑。

### 8.2 补充手工话题或公开链接

点击“补充话题或链接”，选择：

- 手工话题：粘贴你看到的讨论摘要。
- 公开链接：保存一个公开网页地址。

系统不会借此登录网站或抓取私域正文。保存前必须勾选确认。未用于创作的手工来源和热点运行在 30 天后清理；被选中用于文章的来源链保留。

### 8.3 用截图补充热点

可上传 PNG/JPEG 截图，单张不超过 15MB、2500 万像素。截图只交给 Windows 本地 OCR：

1. 上传截图。
2. 检查并修改识别文字。
3. 填写来源标签。
4. 勾选“已核对”。
5. 确认保存或放弃。

确认、放弃或识别失败后，原截图都会永久删除。

### 8.4 从热点开始写作

点击候选中的“用这个选题开始写作”。系统只把热点转换成私人情绪入口，不复制候选标题或来源文章正文。确认后会创建一篇普通文章并进入相同创作流程。

### 8.5 每日计划任务

可在界面人工确认安装每天 09:00 和 20:00 的 Windows 计划任务，也可在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install_trend_tasks.ps1
```

卸载：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\uninstall_trend_tasks.ps1
```

电脑关机或错过时间时不会补跑，同一时段重复触发会保持幂等。

## 9. 内容库怎么使用

“内容库”只显示已经正式进入创作流程的文章。你可以：

- 搜索标题、主题和情绪。
- 按草稿、待审核、已发布等状态筛选。
- 点击任意文章继续上次步骤。
- 查看更新时间和当前流程位置。

内容库不会显示仅粘贴到风格训练、但没有创建为文章的参考原文。

如果内容库是空的，先回到“工作台”创建第一篇文章。只完成了风格训练不会自动产生内容库文章。

## 10. 风格训练怎么使用

### 10.1 喂入参考文章

进入“风格训练”，粘贴一篇 200～20000 字的参考文章，然后点击“提取风格特征”。

无论参考文章本身使用中文还是外语，风格维度、观察、偏好、模仿风险和原创测试短文都会以简体中文反馈。若模型异常返回整段英文，服务端会拒绝保存该结果，并提示重新检查模型配置或再次人工发起分析。

文章会在分析时发送给你配置的 DeepSeek。分析完成后，数据库只保存：

- 不可逆哈希和字符数。
- 抽象风格特征。
- 模仿风险提示。
- 一段原创测试短文。

参考原文和可识别长片段不会长期保存。

### 10.2 确认或拒绝提案

模型提取结果只是待确认提案：

- 点击“确认并加入风格档案”后，规则才影响后续写作。
- 点击“拒绝并丢弃”则不进入风格档案。

不要把人物姓名、独特句子、核心比喻或原文结构当作风格规则确认。应保留节奏、视角、句式倾向、情绪密度等抽象特征。

### 10.3 编辑和回滚风格档案

“当前风格档案”支持人工编辑。保存前必须勾选确认，系统会创建新版本而不是覆盖旧版本。

“风格档案版本”中可以回滚到历史版本。回滚同样会创建一个新版本，历史不会被删除。

### 10.4 从人工修改中学习

文章通过质量门禁并提交待审核后，系统会比较 AI 初稿与最终人工稿，生成修改规律候选，例如：

- 删除某类词语。
- 缩短解释段落。
- 保留某种开头。
- 改变结尾方式。
- 删除不必要文化引用。

候选会显示前后证据和跨文章出现次数。只有你确认的规律才会写入风格档案。

## 11. 编辑宪法

“设置”中的编辑宪法是所有方案、写作、审阅和风格学习的最高优先级边界，包括：

- 核心风格原则。
- 标题与结构规则。
- 禁止出现的 AI 味表达。
- 风格评估维度。

修改后必须人工确认，系统会创建新版本。恢复历史版本也不会覆盖或删除历史。

如果某条风格训练规则与编辑宪法冲突，以编辑宪法为准。

## 12. 封面工作台

文章进入人工编辑后即可使用封面工作台。

### 12.1 上传原图

- 支持 PNG、JPG/JPEG、WebP。
- 单图最大 15MB。
- 系统检查真实图片格式、尺寸、体积和清晰度。
- 每篇文章保留一张当前原图，替换时使用新图。
- 预览不会覆盖原图。

### 12.2 裁剪和缩放

可调整：

- 横向焦点。
- 纵向焦点。
- 1～3 倍缩放。
- 输出宽度和高度。

默认输出为 900×1200、3:4 竖版。自定义尺寸也应保持适合小红书的竖版比例。

### 12.3 三种模板

- 纯文字留白型。
- 杂志标题型。
- 电影字幕型。

封面文案最多 18 个汉字。生成的是实际 PNG 预览，不是只在浏览器中的临时样式。

裁剪、排版和 PNG 预览在本地完成，不调用图片模型。

### 12.4 描述生成图片

先到“设置 → 图像生成”填写：

| 设置 | 填写方式 |
| --- | --- |
| 启用图像生成 | 配置完成后勾选 |
| API Base URL | 服务文档中的公网 HTTPS 基础地址，通常以 `/v1` 结尾，不包含 `/images/generations` |
| 图像模型名称 | 填写你的服务账号可调用的模型名称 |
| 图像 API 密钥 | 进入 Windows 凭据管理器；留空保留当前密钥，更换服务地址需重新填写 |
| 生成超时 | 默认 180 秒，可设为 30～600 秒 |

保存设置不会调用模型。打开已有草稿的文章，在封面工作台输入画面描述，例如：“雨后的窗边，一杯咖啡，暖灰色调，胶片质感；上方留出标题空间，不添加文字。”点击“生成图片”，每次生成一张。

“服务默认”不会发送尺寸参数；“自定义尺寸”填写模型支持的值，例如 `1024x1536`。图片原始尺寸与最终封面的 900×1200 相互独立，选用后可以再裁剪。

候选图片支持查看大图、下载、用作封面和确认删除。生成后先保存为候选，不覆盖当前封面；选择“用作封面”后旧 PNG 预览失效，需重新排版生成。候选图保存在 `uploads/文章ID/generated/`，刷新或重新打开文章后仍可查看。删除候选图片不会删除已选用的封面副本或已经导出的发布包。

点击“重新载入图片”会保留当前尚未保存的封面文案、模板、裁剪和尺寸；重新打开整篇文章仍以最后一次保存的 PNG 设置为准。

仅支持同步 Images 兼容协议，处理 Base64 和图片链接返回；不支持专有任务轮询接口、参考图编辑、多图批量生成或本地 HTTP 模型服务。服务默认的内容审核保持生效。协议参考 [OpenAI 图像生成接口](https://developers.openai.com/api/reference/resources/images/methods/generate)。

如果 Windows 凭据管理器不可用，可在本机 `.env` 中填写：

```dotenv
XR_IMAGE_API_KEY=你的图像密钥
XR_IMAGE_GENERATION_ENABLED=true
XR_IMAGE_BASE_URL=https://服务地址/v1
XR_IMAGE_MODEL=你的图像模型名称
XR_IMAGE_TIMEOUT_SECONDS=180
```

界面保存的图像配置优先于环境默认值，Windows 凭据优先于环境密钥。模型请求仅发送你输入的画面描述和生成参数，不包含正文及历史文章。提供商可能按调用计费，应用不会估算未知价格。

遇到错误时：

- 密钥或权限错误：核对图像密钥及模型权限；写作模型密钥不一定能用于图像服务。
- 接口找不到：核对 Base URL，应用会追加 `/images/generations`，不会自动追加 `/v1`。
- 尺寸不支持：改回“服务默认”，或填写该模型文档允许的尺寸。
- 限流或额度不足：检查服务账户，稍后手动重试。
- 超时或网络中断：上游可能已计费，应用不会自动重试。先点击“重新载入图片”查看是否已保存，并检查服务记录。
- 下载或图片校验失败：当前封面保持不变。只接受公网 HTTPS 图片，文件上限 15 MB、像素上限 4000 万。
- 配置无效或密钥与配置不一致：其他本地封面功能仍可使用。到图像设置重新填写服务地址、模型和该服务的密钥，保存后恢复；检查磁盘空间，避免配置写入中断。

生成时防止重复提交；重新打开文章会显示本次服务进程中仍在进行的请求。关闭后端会中断本地请求，重启后不会补发；上游结果需在服务记录中确认。

## 13. 生成发布包

文章进入待审核后，点击“生成封面与发布包”。发布包保存在：

```text
exports\日期_时间_文章标题_唯一编号\
```

每个发布包包含：

| 文件 | 用途 |
| --- | --- |
| `封面.png` | 手动上传到小红书的封面 |
| `发布内容.txt` | 带 BOM 的纯文本，适合 Windows 打开和复制 |
| `发布内容.md` | Markdown 备份 |
| `手机发布页.html` | 局域网或本机打开后复制标题、正文 |
| `发布清单.json` | 内容 ID、版本、文件列表和自动发布边界 |

如果没有手动生成封面，导出时会使用默认留白模板生成一张封面。

每次导出都会创建一个新的独立目录，即使当天标题相同也不会覆盖旧包。重复渲染同一封面模板也会保留独立 PNG。若浏览器限制手机发布页的剪贴板按钮，可直接选择文字复制，或打开 `发布内容.txt`。

发布前仍应人工检查标题、正文、标签、置顶评论、封面和实际发布时间。

## 14. 手动发布与记录

系统不会替你发布。正确流程是：

1. 打开导出目录。
2. 在小红书客户端中手动上传封面并粘贴正文。
3. 人工检查后发布。
4. 回到文章页面。
5. 粘贴公开笔记链接，填写实际发布时间。
6. 勾选“我确认这篇文章已经由我手动发布”。
7. 点击“标记为已发布”。

只接受可识别的小红书公开链接。记录后，最终文章版本会冻结到发布记录，并进入复盘流程。

## 15. 发布后数据复盘

### 15.1 第 1、3、7 天数据快照

进入“复盘”，系统会提示到期但尚未录入的数据。每篇发布记录支持第 1、3、7 天各一个独立快照。

可以记录：

- 曝光、浏览。
- 点赞、收藏、评论、分享。
- 新增关注、主页访问。
- 完读率、平均阅读时长。
- 粉丝和非粉丝浏览占比。

系统只在存在真实分母时计算互动率或转化率，不会用缺失数据补造比率。

### 15.2 手工录入

选择文章和天数，逐项输入数据，勾选真实数据确认后保存。保存后形成独立快照，不会覆盖其他天数。

### 15.3 数据后台截图 OCR

也可以上传 PNG/JPEG 数据后台截图：

1. 系统在本机识别文字和候选数字。
2. 你逐项检查并修正。
3. 勾选确认后写入数据快照。

与热点截图不同，已确认的数据后台截图默认长期保存在本机，便于审计。你可以点击“永久删除原图”；删除原图不会删除已确认数字快照和 OCR 审计文字。

### 15.4 单篇、周度和月度复盘

- 单篇复盘：读取该文章已确认的第 1/3/7 天快照。
- 周度复盘：最多分析所选 7 天范围内的确认快照。
- 月度复盘：最多分析所选 31 天范围内的确认快照。

报告会展示样本量、输入快照 ID、限制和证据。模型观察的是相关性，不代表因果，也不会猜测平台算法。

报告生成后可以：

- 逐条选择建议并再次确认；或
- 忽略整份报告。

报告历史不会被覆盖。只有最近 3 条已确认建议会作为“可逆小实验”进入后续创作，每篇最多谨慎采用一条，也不会覆盖风格档案。

## 16. 评论回复助手

### 16.1 保存评论

先在“复盘”选择一篇已发布文章。支持两种方式：

- 每行粘贴一条评论，可写成 `昵称：评论内容`。
- 上传评论区 PNG/JPEG 截图，由 Windows 本地 OCR 建议拆分。

每次可保存 1～50 条。时间标签和评论区标题会被忽略；相同文章中重复的昵称与评论组合会去重。

OCR 结果必须逐条核对。确认、放弃或识别失败后，评论截图永久删除，只保留人工确认后的评论文字。

### 16.2 生成回复建议

每一条评论都必须单独勾选：

```text
我确认只把这一条评论发送给 DeepSeek 生成建议
```

勾选只对当前操作有效，不会变成永久授权。模型只收到当前评论、昵称、文章标题和固定安全边界，不会收到其他评论、后台截图、账号密码或历史正文。

回复语气限制为温柔共情、简短克制、轻微幽默或轻微自嘲。安全门会拒绝：

- 未经依据的心理或医学诊断。
- 诱导关注、私聊或添加联系方式。
- 承诺解决对方问题。

### 16.3 复制后人工发送

建议可以先编辑，再点击“复制回复，手动发送”。复制只写入本机剪贴板，不会向小红书发送任何内容。请回到小红书人工确认并发送。

## 17. Provider 与插件安全中心

设置页会展示内置 Provider 的机器可读清单，包括权限、允许域名、读写目录、密钥需求、保留策略、超时和健康检查。

第三方 GitHub 候选的流程是：

1. 保存安全评估。
2. 检查公开仓库元数据、固定提交和 License。
3. 在独立目录做清单校验和静态回归。
4. 人工确认激活注册清单版本。

当前第三方激活是 `manifest_only`：不会下载或执行候选代码，不运行安装/启动脚本，也不会读取浏览器资料、Cookie、验证码或社交账号。只有项目内已实现并测试的内置适配器会真正运行。

普通使用者不需要添加第三方插件。不了解候选仓库和权限时，请保持默认配置。

### 18.1 本地数据位置

### 18.2 不同数据的保留方式

| 数据 | 是否联网 | 保留方式 |
| --- | --- | --- |
| 风格训练参考原文 | 分析时发送给 DeepSeek | 原文不长期保存，只保留哈希、字符数和抽象规则 |
| 热点截图 | 不联网，本地 OCR | 确认、放弃或失败后永久删除 |
| 评论截图 | 不联网，本地 OCR | 确认、放弃或失败后永久删除 |

| 评论回复输入 | 单条授权后发送给 DeepSeek | 建议历史保存在本地 |

### 18.3 备份与迁移

项目没有单独的“一键备份”按钮。建议：

1. 双击 `停止潮湿雨季.bat`。
2. 等待服务完全停止。
3. 复制整个 `小红书` 项目文件夹到备份盘。

如果只备份核心内容，至少保留 `data`、`uploads`、`exports` 和项目配置文件。复制正在写入的数据库可能产生不完整备份，因此必须先停止服务。

Windows 凭据管理器中的 API Key 不会随项目文件夹复制。迁移到另一台电脑后，需要在设置页重新输入 Key。

## 20. 常见问题与排查

### 20.1 双击启动后网页打不开

按顺序检查：

1. 确认已经成功运行过安装程序。
2. 双击 `停止潮湿雨季.bat`，再双击 `启动潮湿雨季.bat`。
3. 手动访问 `http://127.0.0.1:8765`。
4. 访问 `http://127.0.0.1:8765/api/health`，能看到健康响应说明后端正常。
5. 查看 `logs` 目录中的最新日志。
6. 如果端口被占用，先停止旧服务或重启电脑，再启动应用。

当前启动器最多等待 45 秒，不会在服务尚未就绪时提前打开一个无法访问的网页。如果旧进程存在但健康接口不可用，启动器会先调用安全停止程序再创建新实例；停止失败时会保留 PID 记录并明确报错，不会假装启动成功。

### 20.2 内容库打不开或一直空白

先区分两种情况：

- 页面能打开但没有文章：回到工作台创建第一篇文章。风格训练原文不会自动进入内容库。
- 点击“内容库”后报错或白屏：先按 `Ctrl+F5` 强制刷新，再停止并重新启动服务。

继续排查：

1. 打开 `http://127.0.0.1:8765/api/contents`。
2. 如果返回 JSON，说明数据接口正常，通常是浏览器缓存问题。
3. 如果打不开，查看 `logs`，并执行数据库迁移：

```powershell
.\.venv\Scripts\python.exe -m alembic upgrade head
```

4. 不要手工移动或重命名 `data\chaoshi_yuji.db`。

### 20.3 DeepSeek 或 Tavily 测试失败

- 确认 Key 没有多余空格并仍然有效。
- 确认模型名是供应商当前支持的模型。
- 检查网络、代理和防火墙。
- 查看错误提示中的状态码，但不要把完整 Key 粘贴到聊天或日志中。
- 上游失败后系统不会自动重试；修正后由你再次点击测试或生成。

### 20.4 OCR 按钮不可用

- 确认系统是 Windows，并已安装简体中文语言能力。
- 在 Windows“设置 → 时间和语言 → 语言和区域”检查中文语言包。
- 重启应用后重新查看 OCR 状态。
- OCR 不可用时，热点和评论仍可手工粘贴，数据快照仍可手工录入。

### 20.5 OCR 识别不准

- 尽量上传清晰、正向、无遮挡的原图。
- 裁掉无关区域，提高文字占比。
- 不要直接相信识别结果；逐字、逐项校正后再勾选确认。
- 评论截图如被合并成一行，按“昵称：正文”格式手工分行。

### 20.6 生成三个方案显示“请求失败”

旧版本可能在模型把叙事结构、场景或情绪曲线写成一段中文而不是 JSON 列表时拒绝结果；第一次失败后再次点击还可能被旧幂等键阻止。当前版本会把非空中文段落、箭头序列和分行内容规范化为列表，并为同一输入记录独立尝试次数。失败历史、错误摘要和可取得的 Token 用量都会保留，重新点击不会覆盖旧记录。

如果仍停留在旧错误页面，按 `Ctrl+F5`，从内容库重新打开文章。已经成功生成的方案会直接显示，不需要再次调用模型。

#### 20.6.1 初稿提示“0 格式不符合约定”或“虚构说明必须是列表”

这是旧版对模型 JSON 结构过于严格造成的，不是你选择的细节有问题，也不会损坏文章、方案或内容库。模型可能把文化引用写成普通文字，把虚构说明写成一段话；当前版本会在不改变原意的前提下自动转换为可保存、可核验的数组和对象，并在无法安全转换时显示“文化引用”等中文字段名，不再显示没有意义的数组索引 `0`。

更新后的处理顺序：

1. 按 `Ctrl+F5` 强制刷新页面。
2. 从内容库重新打开这篇文章。
3. 如果文章已经进入人工编辑，直接继续修改，不要再次生成。
4. 如果仍在细节确认页，只点击一次“生成初稿”；失败的旧尝试会保留，新尝试不会覆盖历史。

不要删除文章或重新选择虚构细节来处理此错误。若新版仍失败，保留页面上的中文字段提示，并检查设置页的 DeepSeek 连接状态。

### 20.7 质量门禁无法提交

- 查看原创度是否在当前检测范围通过。
- 查看文化引用是否存在“未核实”或“部分核实”。
- 查看风险报告是否存在阻止项。
- 修改正文并保存新版本后，重新运行五项质量门禁。

#### 20.7.1 风格审阅提示缺少 dimensions、issues、strengths 或 summary

这是旧版模型把审阅结果放进额外 JSON 外层造成的格式错误，不表示正文为空，也不会删除人工稿。当前版本会安全展开唯一的一层审阅对象，并把“保留的自然表达”等单段文字转换成数组；风格、AI 味和风险审阅 Prompt 也已明确固定顶层字段。

处理方法：

1. 按 `Ctrl+F5` 强制刷新。
2. 从内容库重新打开文章。
3. 已经出现五项审阅结果时直接查看，不要重复运行。
4. 若仍没有结果，只点击一次“运行质量检查”；已经成功的审阅会复用，只从失败步骤继续。

旧失败记录会保留用于审计，但不会覆盖新版成功报告。新版错误会显示“评价维度”“问题列表”“风险列表”等中文字段，不再直接暴露内部英文字段名。

### 20.8 找不到导出文件

文章必须先通过质量门禁并进入待审核。点击“生成封面与发布包”后，查看界面显示的完整路径，或打开项目中的 `exports` 目录。

### 20.9 手机访问不了局域网地址

- 必须使用 `启动潮湿雨季_局域网.bat`。
- 手机和电脑必须在同一 Wi-Fi。
- Windows 防火墙只允许专用网络访问。
- 路由器若开启访客隔离，手机可能无法访问电脑。
- 不要把局域网端口映射到公网。

### 20.10 计划任务没有刷新热点

- 确认计划任务已经安装。
- 确认 09:00 或 20:00 时电脑处于开机状态。
- 错过时间不会补跑，可回到工作台手动刷新。
- DeepSeek/Tavily Key、网络或上游服务异常都会让本次任务停止。

如果旧记录曾显示 `data_status`、`validation error` 或 Pydantic 英文链接，表示模型把解释句写进了机器状态字段，并不代表公开来源、文章或内容库损坏。当前版本会根据最终有效候选数量自动计算状态，不再采用模型填写的枚举；其他模型格式问题也只显示简短中文。更新后刷新页面，再人工点击一次“手动刷新”即可，不要连续重复点击。

### 20.11 想确认系统是否完整

在项目根目录运行后端测试：

```powershell
.\.venv\Scripts\python.exe -m pytest backend\tests -q
```

运行前端测试和构建：

```powershell
cd frontend
npm.cmd test -- --run
npm.cmd run lint
npm.cmd run build
```

## 21. 明确不支持的操作

为了隐私、平台边界和结果可控，系统不会提供：

- 小红书账号登录或 Cookie 读取。
- 验证码处理或反爬绕过。
- 抓取客户端内、私域或未公开内容。
- 自动发布笔记。
- 自动点赞、关注、评论或回复。
- 把有限公开网页检查宣传成“全网原创保证”。
- 未经确认就把风格提案、复盘建议或评论发送给模型。

```text
确认式复盘 → 评论逐条授权生成建议 → 复制后人工发送 → 停止应用
```

遇到问题时，优先保留 `data`、`uploads` 和 `exports`，不要直接删除数据库或重新安装整个项目；先停止服务、查看日志，再按本说明的排查顺序处理。

## 发布准备版的界面与安装调整

设置页新增“模型与连接 / 写作边界 / 高级插件设置”快捷分组；风格训练页优先显示当前规则，可展开编辑宪法，并在版本历史中比较规则差异。手机底部导航保留文字名称。

安装会检查依赖版本并在失败时停止；仅检查环境可运行 `scripts/bootstrap.ps1 -CheckOnly`。启动日志位于 `logs/startup.log`，可通过 `.env` 的 `XR_PORT` 修改日常服务端口。

迁移到新电脑前先停止服务，备份数据目录；新电脑需要重新运行安装脚本并配置 API Key，不要复用原电脑的 `.venv` 或 `node_modules`。公开发布源码请使用开发说明中的整理工具，不要上传整个日常使用目录。
