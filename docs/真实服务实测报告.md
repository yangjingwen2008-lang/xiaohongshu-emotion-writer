## 实测发现并修复的问题

### 多张 OCR 截图相互覆盖

用真实 Windows 中文 OCR 识别“雨停以后，再走一小段。”和“周五下班，街灯慢慢亮了。”，两段文字均完整识别。随后逐张下载预览并核对原始图片摘要，发现第一张预览变成了第二张。

原因是 OCR 记录的 ID 原本由数据库插入时生成，写文件却发生在插入之前，多个文件使用了相同的临时名称。热点、复盘、评论三类上传现已在写文件前生成独立 ID。

修复后再次通过真实 Windows OCR 上传不同图片，两个预览分别与各自原图一致；确认第一张后只删除第一张，第二张仍可读取。三类上传均补充“多图保留与单张删除”的回归测试。

### 创建文章失败没有页面提示

在真实页面输入超过接口上限的主题，服务端正常返回 422，但界面没有显示原因，错误只出现在浏览器控制台。

已增加可见错误提示、输入长度限制和纯空白检查，失败后保留用户填写内容。修复后通过边界测试人为移除浏览器长度限制，触发真实 422 响应：页面显示错误，输入保留，浏览器未处理异常为 0。
