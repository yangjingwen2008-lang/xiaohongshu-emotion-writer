# 技术决策

更新日期：2026-09-12

## 架构与兼容

- FastAPI + SQLAlchemy + SQLite 负责本地数据与工作流；React + Vite + Tiptap 负责界面和编辑。
- 生产服务同时提供 API 和前端静态文件。页面延迟加载，首页不加载富文本编辑器。
- API 按业务拆分，公共依赖集中管理，既有接口和依赖覆盖入口保持兼容。未知 `/api/*` 返回 JSON 404，不再回落到前端 HTML。
- 逻辑 Agent 负责生成结构化产物；只有编排器改变创作状态。模型结果通过 Pydantic 校验后才保存。
- 数据库迁移遵循应用数据目录。现有内容、编辑宪法、风格历史和人工确认语义保持不变。

## 配置与启动

- Windows 凭据管理器优先，环境变量使用 `XR_` 前缀；示例文件不包含密钥。
- 安装脚本检查 Python 和 Node.js 版本，采用 npm 锁文件与 Python 约束文件，任一步失败立即停止。
- 启动器根据健康状态与项目实例标识复用当前服务，日志写入本地文件。PID 文件独占创建，避免重复启动覆盖记录。
- 停止 Windows 服务前核对命令行中的 Python 路径与服务模块，过期 PID 指向其他程序时不结束该程序。
- 默认绑定本机地址；局域网需显式选择，切换模式前先停止旧服务。没有公网认证方案，不作为公网服务部署。

## 数据与联网边界

- 文章、版本、运行记录、来源摘要和已确认复盘数据存入本地 SQLite。
- 需要模型的步骤通过 DeepSeek 适配器调用；公开检索通过 Tavily，保存有限摘要、证据链接、请求标识和用量记录。
- 原创度检查覆盖本地历史、人工补充来源和可访问的公开搜索摘要；不访问私域正文，也不承诺全网覆盖。
- 文化引用仅核验正文仍保留的引用，未核实结果参与提交门禁；上游失败不自动重试或切换来源。
- OCR 使用 Windows 本地能力。热点和评论临时截图按确认/放弃/失败流程删除；复盘原图可长期保留并由用户显式删除。
- 模型名称由用户配置。设置页不再将旧价格写成当前价格或覆盖已有价格记录，本文不承诺服务商现行价格与模型可用性。

## 图像生成

- `ImageGenerationProvider` 使用现有 httpx 依赖，按同步 Images 协议提交描述、模型、`n=1` 和可选尺寸，兼容 Base64 与 URL 返回。Base URL 必须为公网 HTTPS，调用前解析域名并固定连接到通过公网检查的 IP，保持原 Host 与 TLS SNI。
- 图片下载最多跟随三次重定向，每次重新校验公网地址；下载请求不携带 API Authorization 或先前响应的 Cookie。禁用连接复用以隔离解析到同一 IP 的不同 TLS 域名。忽略环境代理，防止请求经未声明的代理转发。网络请求总时限默认 180 秒，不自动重试或换源。
- 图像设置保存在 `AppSetting`，密钥只由 `SecretStore` 保存；配置响应和校验错误不回传原始输入。HTTP 客户端的 URL 日志关闭，避免签名下载链接进入日志。
- 使用 `GeneratedCoverImage` Artifact 保存描述、模型、尺寸和本地候选文件名，不保存上游下载链接或原始响应；已有数据库结构足够，无新增迁移或依赖。
- 候选图位于文章上传目录的 `generated` 子目录，选用时复制并复用封面校验，清除旧渲染预览。候选删除与当前封面、历史导出相互独立。
- 本机 uvicorn 单 worker 下用进程内互斥集合防止同文章同时生成；浏览器只轮询状态，不补发生图请求。进程退出后不恢复未完成请求，不承诺上游取消或退款。多 worker/公网任务队列不在本次实现范围。
- 成功保存时记录服务返回的 Token 用量（如有），不虚构费用。当前只支持文字生图，不支持编辑、批量、流式或服务商异步任务协议。

## 人工决定与版本

- 编辑宪法是写作边界；风格训练、手工偏好和修改规律只有确认后才影响后续写作。
- 版本比较展示当前规则相对历史版本的增加和移除；恢复创建新版本，保留历史。
- 富文本保存保留旧版本。文章由用户手动发布，评论建议只供复制后人工发送。
- 复盘仅分析人工确认的数据，有真实分母才计算相关比率；建议逐条确认，限制为可逆实验。

## 插件与发布

- 第三方候选当前仅执行静态清单评估和清单注册，不下载运行候选代码；真实可执行 Provider 仅限内置实现。
- 公开副本从源码白名单生成，排除数据、环境和开发历史；保留原项目供日常使用与追溯。
- 本轮无新增数据库结构迁移，健康接口新增 `instance_id` 为兼容性扩展。
